Invite flow

Главная демонстрация продукта: клиент не пересылает общий файл, а создает одноразовую ссылку для каждого устройства.

Клиент создает ссылку

Система проверяет подписку и свободные слоты. Токен хранится только в hash-виде.

Друг открывает invite

Пользователь выбирает платформу, указывает имя устройства и подтверждает активацию.

Выпускается сертификат

PKI генерирует уникальный client certificate и identity вида customer-d01.

Профиль готов

Выдается `.mobileconfig`, `.sswan` или Windows `.zip`. Invite сразу сгорает.

Anti-sharing policy

Один профиль не работает на двух устройствах одновременно.

На стороне strongSwan используется политика `unique = keep`, чтобы копия профиля не выбивала исходное устройство.

connections {
  ikev2-pubkey {
    version = 2
    unique = keep
    remote {
      auth = pubkey
      id = %any
    }
  }
}
